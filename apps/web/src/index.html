Requires macOS 13+ and Xcode Command Line Tools with Swift 5.9+.

A few things to know.

Can I download a ready-made app?

Not yet. The project currently provides source code and local builds, not a notarized binary release. The commands above build an ad-hoc signed app for your Mac.

Will it fix display scaling?

It selects mirror or extend mode and the mirror source. macOS and your hardware still determine supported resolutions. Different aspect ratios can produce scaling or black bars.

What about privacy and compatibility?

No analytics, screen capture, or application network requests are implemented. Full multi-display hardware and UI testing is still in progress. Review the testing checklist before relying on it in a presentation.
